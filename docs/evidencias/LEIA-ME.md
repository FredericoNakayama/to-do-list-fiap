# Evidências

Coloque nesta pasta as capturas de tela (emulador ou dispositivo) que comprovam cada item abaixo. Renomeie os arquivos com nomes descritivos (ex: `01-lista-inicial.png`) e depois linke as imagens na seção "Evidências" do README.md, por exemplo:

```
![Lista inicial](docs/evidencias/01-lista-inicial.png)
```

Itens obrigatórios:

- [ ] Tela inicial com a lista de tarefas em execução
- [ ] Cadastro de uma nova tarefa
- [ ] Tarefa cadastrada aparecendo na lista
- [ ] Edição de uma tarefa existente
- [ ] Tarefa marcada como concluída
- [ ] Exclusão de uma tarefa
- [ ] Navegação entre a lista e o formulário
- [ ] Build ou execução do projeto sem erros

Prints ilegíveis, cortados ou que não demonstrem claramente a funcionalidade podem não ser considerados — pode apagar este arquivo depois de colocar as imagens, ou deixá-lo como está.
